# CRUD Practice

Un proyecto de práctica para implementar operaciones CRUD (Crear, Leer, Actualizar, Eliminar) en una aplicación web.

## Descripción

Este proyecto es una aplicación web desarrollada para practicar las operaciones fundamentales de CRUD. Utiliza tecnologías web estándar como HTML, CSS y JavaScript, con el framework Bootstrap para mejorar la interfaz de usuario.

## Características

- Operaciones CRUD completas
- Interfaz de usuario responsiva con Bootstrap
- Estructura organizada en HTML, CSS y JavaScript
- Página de administración separada

## Estructura del Proyecto

```
/workspace/
├── index.html          # Página principal
├── css/
│   └── style.css       # Estilos personalizados
├── js/
│   └── app.js          # Lógica de JavaScript
└── pages/
    └── administrador.html  # Página de administración
```

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.2.3 (CDN)

## Instalación

1. Clona este repositorio:
```bash
git clone https://github.com/mSanchezDeveloper/cute-weather-app
```

2. Navega al directorio del proyecto:
```bash
cd nombre-del-repositorio
```

3. Abre `index.html` en tu navegador preferido.

## Uso

1. Abre la aplicación en tu navegador web
2. Utiliza las diferentes funcionalidades CRUD según estén implementadas
3. Accede a la página de administración si es necesario
